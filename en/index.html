AI-native

Connect your AI coding assistant

Connect through Cursor’s Add to Cursor link, or run the installer for Codex or Claude Code. The Agent Skill provides EVEngine guidance, while MCP lets your assistant work with the engine to write scripts, run and debug your game, and package builds.

Quick setup 
# macOS / Linux / Git Bash (tool: codex | cursor | claude)
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.sh | bash -s codex

# Windows PowerShell (defaults to Codex)
irm https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.ps1 | iex

The installer adds the skill to your assistant’s global skills directory. If eve is on your PATH, it also registers the MCP server. To choose another assistant in Windows PowerShell: iex ((irm https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.ps1) + ' -Tool cursor')。

Codex skill + MCP

The skill teaches Codex how to use eve: locate the SDK, create projects, edit scripts, run games, and package builds.

# 1) Install the skill for your user account (all projects)
mkdir -p ~/.agents/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.agents/skills/evengine/SKILL.md

# 2) Connect Codex to the engine through MCP (root defaults to the current project)
codex mcp add evengine -- eve mcp

Alternatively, add [mcp_servers.evengine] with command = "eve" and args = ["mcp"] to ~/.codex/config.toml. Add --root <dir> to the arguments to specify your game directory.

Cursor skill + MCP

Cursor loads skills from .agents/skills, .cursor/skills, and their global equivalents. Install globally to use the skill across projects.

Add to Cursor ↗ 
# Install the skill globally; MCP requires eve on your PATH
mkdir -p ~/.cursor/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.cursor/skills/evengine/SKILL.md

# Or create .cursor/mcp.json in your project root
{ "mcpServers": { "evengine": {
    "command": "eve",
    "args": ["mcp"]
} } }

To share the skill with your team, add it to .cursor/skills/evengine/ in your game repository. The MCP server uses the open project directory as the game root by default.

Claude Code skill + MCP

Claude Code supports the Agent Skills open standard, so the same SKILL.md works here too. Install it for your user account or a specific project.

# 1) Install the skill for your user account
mkdir -p ~/.claude/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.claude/skills/evengine/SKILL.md

# 2) Register the MCP server
claude mcp add evengine -- eve mcp

To share the setup through your repository, add the skill under .claude/skills/ and configure MCP in the project’s .mcp.json.

eve mcp is an MCP server for AI coding tools; it does not include a language model. Your assistant starts it automatically using the MCP configuration above. No manual startup is needed.
