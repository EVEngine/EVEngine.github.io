AI-native

给 AI 用户的一键接入

EVEngine 从设计上就欢迎 AI 参与：克隆仓库即得一个 Codex skill，本地再跑一个 MCP 桥，AI 就能直接构建、运行、调试你的游戏。

一键 Skill Codex

克隆仓库后，Codex 会自动加载 .cursor/skills/evengine：构建、运行示例、改 Squirrel 脚本、查模块用法，全都有现成指引。

# 一步到位：clone 即接入
git clone --recurse-submodules https://github.com/EVEngine/EVEngine.git
cd EVEngine
# 然后直接对 Codex 说：
“用 EVEngine 给我做个打砖块，跑起来”

Skill 内含：构建/运行命令、Squirrel 入口约定、模块手册索引、常见平台坑（Vulkan SDK / 无头环境）。

本地 MCP eve-mcp

让 AI 直连一个正在运行的引擎会话：暂停、求值、截帧、切片报错，都在 tools/eve-mcp 里现成可用。

# 1) 带 MCP 端口启动游戏
eve run --debug --mcp-port=7529 examples/basic

# 2) 在 Codex / Cursor / Claude Desktop 配置
mcpServers: {
  evengine: { command: "node",
    args: ["tools/eve-mcp/server.js"],
    env: { EVE_MCP_HOST: "127.0.0.1",
           EVE_MCP_PORT: "7529" } } }

可用工具：eve_status / eve_eval / eve_pause / eve_snapshot_capture / eve_error_slice。
