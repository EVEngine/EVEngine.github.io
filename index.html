AI-native

一键接入你的 AI 工具

浏览器不能直接操作你的终端，所以给两种一键方式：Cursor 有官方的 Add to Cursor 真跳转；Codex / Claude 用一条命令装好。装完 skill + MCP，AI 就能直接帮你写脚本、运行、调试、打包游戏。

一条命令装全家桶 
# macOS / Linux / Git Bash（工具：codex | cursor | claude）
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.sh | bash -s codex

# Windows PowerShell（默认装给 Codex）
irm https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.ps1 | iex

脚本自动把 skill 放进对应工具的全局目录；检测到 eve 在 PATH 时，顺带注册 MCP。 Windows PowerShell 换工具：iex ((irm https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/scripts/install-skill.ps1) + ' -Tool cursor')。

Codex skill + MCP

装上 skill 后，Codex 自动知道怎么用 eve：定位 SDK、建工程、改脚本、运行、打包。

# 1) 装 skill（用户级，所有项目可用）
mkdir -p ~/.agents/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.agents/skills/evengine/SKILL.md

# 2) 加 MCP，让 Codex 直连引擎（默认根目录 = 当前项目）
codex mcp add evengine -- eve mcp

也可写进 ~/.codex/config.toml：[mcp_servers.evengine] + command = "eve"、args = ["mcp"]。需要指定游戏目录时加 --root <dir>。

Cursor skill + MCP

Cursor 会自动加载 .agents/skills、.cursor/skills 及对应全局目录，装一次全项目可用。

Add to Cursor · 点一下装 MCP ↗ 
# 装 skill（全局；需要 eve 在 PATH 上）
mkdir -p ~/.cursor/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.cursor/skills/evengine/SKILL.md

# 或项目根目录建 .cursor/mcp.json
{ "mcpServers": { "evengine": {
    "command": "eve",
    "args": ["mcp"]
} } }

也可以放进游戏仓库的 .cursor/skills/evengine/，随仓库共享给整个团队。MCP 默认以打开的项目目录为游戏根目录。

Claude Code skill + MCP

Claude 遵循 Agent Skills 开放标准，同一个 SKILL.md 直接用；个人级或项目级都行。

# 1) 装 skill（个人级）
mkdir -p ~/.claude/skills/evengine && \
curl -fsSL https://raw.githubusercontent.com/EVEngine/EVEngine.github.io/main/skills/evengine/SKILL.md \
  -o ~/.claude/skills/evengine/SKILL.md

# 2) 加 MCP
claude mcp add evengine -- eve mcp

或写进项目 .claude/skills/ 与 .mcp.json，随仓库共享。

注：eve mcp 是供 AI 工具链调用的 MCP 服务，本身不含大模型，单独运行没有意义；它由上面的工具通过 MCP 配置自动拉起，无需手动启动。
